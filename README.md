# CODSOFT_TASKSNO1

A collection of CODSOFT programming tasks. This repository currently includes a Java number guessing game.

## Number Game

The game picks a number from 1 to 100. You have seven attempts per round, earn points for correct guesses, and can play multiple rounds.

### Run

Requires a Java Development Kit (JDK).

```powershell
javac NumberGame.java
java NumberGame
```
